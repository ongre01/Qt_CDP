# Qt_CDP 문서

`Qt_CDP`는 Qt Widgets 기반의 데스크톱 프로그램입니다. 별도 Chrome 프로필을 Chrome DevTools Protocol(CDP) 모드로 실행하거나, 로컬 CDP 엔드포인트에 연결하여 다음 작업을 지원합니다.

- 코레일 회원번호 로그인 자동화
- 열린 열차 조회 탭의 DOM 스냅샷 수집과 열차 정보 표시
- 선택한 열차의 예매 가능 여부를 병렬로 확인하고, 선택 시 자동 예매 시도
- 방문 페이지 DOM 스냅샷의 로컬 저장

## 빠른 시작

1. Qt Creator에서 `Qt_CDP.pro`를 열고 `widgets`, `network`, `websockets` 모듈을 포함한 C++17 Kit을 선택합니다.
2. 빌드하여 프로그램을 실행합니다.
3. Chrome 실행 파일과 CDP 전용 사용자 데이터 디렉터리를 확인한 뒤 **CDP용 Chrome 시작**을 누릅니다.
4. Chrome이 준비되면 열차 정보 수집이 자동으로 시작됩니다. Chrome에서 코레일 열차 조회 페이지를 엽니다.
5. 표시된 탭별 열차 목록에서 대상 열차를 선택하고, 필요할 때 **병렬 매크로 시작**을 누릅니다.

자동 로그인, 열차 정보 수집, 방문 페이지 기록은 모두 로컬 호스트 CDP 주소만 허용합니다. 기본 주소는 `http://127.0.0.1:9222`입니다.

## 범위와 책임

이 프로그램은 브라우저를 자동으로 제어합니다. 사용자는 코레일의 이용약관, 결제·예매 조건, 그리고 자동화 사용에 적용되는 규정을 직접 확인하고 준수해야 합니다. 자동화 결과나 예매 성공은 보장되지 않으므로, 실제 예약 상태는 브라우저와 코레일 서비스에서 확인해야 합니다.
